## 1. 这个链接的三大组成要素解密

拆开来看，`http://192.168.1.188:8088/live.m3u` 对应了三个核心部分：

```text
http:// 192.168.1.188 : 8088 / live.m3u
───┬─── ───────┬─────── ──┬── ────┬────
   │           │          │       └─ 3. 文件名：Termux 目录下存放的标准电视频道清单文件
   │           │          └───────── 2. 端口号：你在 Termux 里指定的网络服务门牌号（8088）
   │           └──────────────────── 1. 局域网 IP：家里路由器通过 Wi-Fi 分配给手机的内网地址
   └──────────────────────────────── 传输协议：标准网页 HTTP 协议
```

只要满足这三点，不管是电视上的 TiviLite，还是客厅的电脑、iPad，只要连着家里的同一个 Wi-Fi，输入这个网址就能立刻把源拉取过去播放！

## 2. 从零复现搭建全过程（5分钟完整实操）

### 第一步：准备 Termux 基础环境
打开旧安卓手机上的 Termux，逐行输入以下命令：

```bash
# 1. 开启后台不休眠锁
termux-wake-lock

# 2. 安装 Python 环境（用来提供网页服务器）
pkg update -y
pkg install -y python
```

---

### 第二步：制作/生成你的频道文件 `live.m3u`

在 Termux 里创建一个专门存放电视源的文件夹 `iptv`，并在里面生成 `live.m3u` 文件：

```bash
# 创建目录并进入
mkdir -p ~/iptv && cd ~/iptv
```

通过文本编辑器编辑你的频道列表（或者直接执行以下命令生成一个基础模板）：

```bash
cat << 'EOF' > ~/iptv/live.m3u
#EXTM3U x-tvg-url="http://epg.51zmt.top:8000/api/diyp/"
#EXTINF:-1 tvg-name="CCTV1" tvg-id="CCTV1" tvg-logo="https://live.fanmingming.com/tv/CCTV1.png" group-title="央视频道",CCTV-1 综合
http://你的直播流播放地址1.m3u8
#EXTINF:-1 tvg-name="CCTV5" tvg-id="CCTV5" tvg-logo="https://live.fanmingming.com/tv/CCTV5.png" group-title="央视频道",CCTV-5 体育
http://你的直播流播放地址2.m3u8
#EXTINF:-1 tvg-name="湖南卫视" tvg-id="湖南卫视" tvg-logo="https://live.fanmingming.com/tv/湖南卫视.png" group-title="卫视频道",湖南卫视高清
http://你的直播流播放地址3.m3u8
EOF
```

> **小技巧**：如果你在电脑或手机文件管理器里已经有一个整理好的 `my_channels.m3u`，也可以直接把它重命名为 `live.m3u`，复制到手机的 `~/iptv/` 目录下。

---

### 第三步：启动 8088 端口 HTTP 服务器

在 Termux 中运行 Python 内置的极轻量 HTTP 服务器，指定根目录为 `~/iptv`，端口为 `8088`：

```bash
cd ~/iptv
python3 -m http.server 8088
```

此时终端会显示：
```text
Serving HTTP on 0.0.0.0 port 8088 (http://0.0.0.0:8088/) ...
```
这表明手机已经成功在 `8088` 端口上开启了局域网广播！

---

### 第四步：确认手机内网 IP 为 192.168.1.188

在手机上打开 Wi-Fi 详情，或者在 Termux 新窗口输入：

```bash
ip route get 1.1.1.1
```
或者输入：
```bash
ifconfig wlan0 | grep "inet "
```

屏幕输出中的 `src 192.168.1.188`，就是你手机当前的局域网 IP！

此时：
* IP：`192.168.1.188`
* 端口：`8088`
* 文件：`live.m3u`
组合在一起，专属的订阅链接就正式诞生了：
👉 **`http://192.168.1.188:8088/live.m3u`**！

---

### 第五步：后台静默保活（熄屏不掉线）

如果你直接关闭 Termux 界面，服务器就会停止。要让它像真正的服务器一样在后台 7×24 小时运行，使用 `nohup` 命令启动：

```bash
# 杀掉之前的临时前台进程（如果有）
pkill -f "http.server 8088"

# 使用 nohup 放在后台持久运行
nohup python3 -m http.server 8088 --directory ~/iptv > ~/iptv.log 2>&1 &
```

* 输入 `ps aux | grep 8088`，能看到进程常驻说明运行成功；
* 配合安卓手机设置：
  1. 打开手机设置 ->【应用管理】->【Termux】->【省电策略】选 **【无限制 / 允许后台高耗电】**；
  2. 多任务卡片界面把 Termux **加锁 🔒**；
  3. 插上充电线，手机息屏也不会中断！

## 3. 进阶关键：让 192.168.1.188 永不变动的路由器设置

很多朋友第二天发现电视打不开了，原因不是手机关机了，而是：**路由器重启后，把手机的 IP 从 `192.168.1.188` 重新分配成了 `192.168.1.120`，导致链接失效！**

### 解决方法：在路由器上把 192.168.1.188 绑定给这台手机
1. 电脑或手机浏览器打开路由器后台（如 `192.168.1.1`）；
2. 找到 **【网络设置】** 或 **【DHCP 静态 IP 分配 / 静态地址保留】**；
3. 找到你的这台 Termux 手机设备名称（或 MAC 地址），将 IP 永久指定绑定为：
   `192.168.1.188`；
4. 点击保存。此后无论路由器断电重启还是手机重连 Wi-Fi，手机 IP 永远固定是 `192.168.1.188`，电视订阅链接永久有效！

## 4. 高级进阶：让 `live.m3u` 每天自动更新/自动测速剔除死链

如果你的频道源是网上搜集的动态源，容易失效，你可以编写一个每天自动抓取最新源并覆盖 `~/iptv/live.m3u` 的定时任务：

在 Termux 里创建更新脚本 `nano ~/update_iptv.sh`：

```bash
#!/bin/bash
# 每天自动从你的 GitHub 或订阅源拉取最新可用源并替换
SOURCE_URL="https://raw.githubusercontent.com/某优质直播源仓库/main/tv.m3u"

echo "正在更新直播源..."
curl -s -L "$SOURCE_URL" -o ~/iptv/live.m3u.tmp

if [ -s ~/iptv/live.m3u.tmp ]; then
    mv ~/iptv/live.m3u.tmp ~/iptv/live.m3u
    echo "更新成功！最新 live.m3u 已生效。"
else
    echo "拉取失败，保留原有文件。"
    rm -f ~/iptv/live.m3u.tmp
fi
```

赋予执行权限：
```bash
chmod +x ~/update_iptv.sh
```

利用 Termux 的定时任务每天凌晨 4 点自动更新一次，你的 `http://192.168.1.188:8088/live.m3u` 就会永远保持最新、永不死链！
