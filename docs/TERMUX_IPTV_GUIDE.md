## 第一部分：朋友怎么直接看我（已搭建好）的直播源？

如果你的朋友和你**在同一个家庭 Wi-Fi 下**，或者你已经通过内网穿透生成了链接，朋友只需按以下步骤操作，30 秒即可在电视或手机上看上电视：

### 步骤 1：安装播放器客户端
在电视盒子或手机上安装 **TiviLite (灵动TV)** 开源播放器（安装包仅 7.5MB，无任何广告弹窗）：
* 官方下载链接：[https://github.com/fullofjoy/tivilite/releases](https://github.com/fullofjoy/tivilite/releases)

### 步骤 2：手机扫码一键配源（最爽体验，免插 U 盘）
1. 电视打开 **TiviLite**，按遥控器菜单键或进入设置，点击 **【扫码配源 / Web后台】**；
2. 电视屏幕上会弹出一个二维码；
3. 拿起手机（连接家里同一个 Wi-Fi），微信或浏览器扫一扫二维码，手机上会打开一个配置后台；
4. 将你给朋友的订阅链接（形如：`http://192.168.1.188:8088/live.m3u`）粘贴进去，点击 **【立即发送到电视】**；
5. 电视画面 0.2 秒瞬间加载起播，换台秒开！

## 第二部分：朋友自己也想用旧手机搭建一个？（保姆级实战）

如果朋友手里也有一台闲置旧安卓手机，想在自己家里搭一个专属源服务器，直接照着下面操作：

### 1. 准备工作
1. **一部闲置安卓手机**（Android 7.0 以上皆可，无需 Root）；
2. **下载安装 Termux**：
   * ⚠️ **特别提醒**：千万不要在各大手机自带的应用商店下载（版本过老已被官方弃用）；
   * 请在开源官网或 F-Droid 下载最新安装包：[Termux GitHub Release 下载页面](https://github.com/termux/termux-app/releases)（选择 `termux-app_v..._arm64-v8a.apk`）。

---

### 2. Termux 基础环境初始化

打开手机上的 Termux 应用（黑色命令行界面），逐行复制执行以下命令：

#### 2.1 申请存储权限与开启后台锁（防止手机息屏断开）
```bash
termux-setup-storage
termux-wake-lock
```
*(弹窗提示权限请求时，一律点击【允许】)*

#### 2.2 换国内镜像源并更新核心组件
输入以下命令一键换清华大学开源镜像源，飞速下载依赖：
```bash
sed -i 's@^\(deb.*stable main\)$@#\1\ndeb https://mirrors.tuna.tsinghua.edu.cn/termux/apt/termux-main stable main@' $PREFIX/etc/apt/sources.list
pkg update -y && pkg upgrade -y
```

#### 2.3 安装必备运行环境 (Python / Git / Curl)
```bash
pkg install -y git python curl wget
```

---

### 3. 部署直播源代理服务

这里介绍两种最常用的部署方式，根据需求任选一种即可：

#### 方式 A：轻量静态 M3U 文件托管（最简单，适合已有好源的朋友）
1. 在 Termux 中新建一个目录并放好你的直播源：
```bash
mkdir -p ~/iptv && cd ~/iptv
```
2. 把你收集或整理好的 `live.m3u` 文件放到该目录下（可以通过手机文件管理器复制到 Termux 内部，或直接通过 curl 下载）。
3. 使用 Python 一键开启超轻量 HTTP 服务：
```bash
nohup python3 -m http.server 8088 --directory ~/iptv > ~/iptv.log 2>&1 &
```
> 服务已在后台静默运行，端口为 `8088`。

#### 方式 B：动态聚合代理（适合央视频 YSP / 地方台动态 Token 自动刷新）
如果你用的是网络上开源的 Python/Node 动态解析项目（例如 Pixman、allinone 等代理脚本）：
```bash
cd ~
git clone https://github.com/某开源项目/iptv_proxy.git
cd iptv_proxy
pip install -r requirements.txt
nohup python3 main.py > ~/proxy.log 2>&1 &
```

### 4. 设置防杀后台与开机自启（关键一步）

旧安卓手机最容易出现的问题是：**锁屏十几分钟后，系统省电策略把 Termux 杀掉了**。只需完成以下 3 项设置，手机就能像服务器一样常年不断电稳定运行：

1. **电池无限制**：
   * 打开手机【系统设置】->【应用管理】-> 找到【Termux】；
   * 【电池 / 耗电管理】-> 改为 **【无限制】** 或 **【允许后台高耗电运行】**。
2. **后台任务加锁**：
   * 打开手机多任务后台切换界面，找到 Termux 窗口，向下拉或长按，点击 **【锁定 🔒】** 图标。
3. **查看你的内网 IP 地址**：
   在 Termux 终端输入：
   ```bash
   ifconfig wlan0 | grep "inet "
   ```
   或者直接输入：
   ```bash
   ip a
   ```
   找到 `wlan0` 下面的 IP 地址，比如显示 `192.168.1.188`。
   此时你的专属直播源订阅链接就是：
   👉 **`http://192.168.1.188:8088/live.m3u`**

4. **手机常插充电器**：
   将这台旧手机插上充电线，放在客厅电视柜角落或路由器旁边，连接 Wi-Fi，静默运行，每月电费不到 1 块钱！

## 第三部分：进阶：怎么让不在同一个 Wi-Fi 的外地朋友也能看？

如果你的朋友住在别的小区，或者想在老家、出差酒店也能看你在家里 Termux 手机上运行的电视源：

### 推荐方案：免费虚拟异地组网 (Tailscale)
无需公网 IP，不花一分钱，安全不被封：

1. **手机端 Termux 安装 Tailscale**：
   Termux 社区提供了现成的 Tailscale 包：
   ```bash
   pkg install tailscale
   tailscaled &
   tailscale up
   ```
   终端会输出一个授权网址，浏览器打开登录你的账号（支持微软/谷歌/GitHub 一键登录）。
2. **朋友的设备也安装 Tailscale**：
   * 朋友在自己的手机、电脑或电视盒子上安装 Tailscale 客户端，登录同一个组网账号；
   * 此时朋友的设备与你的 Termux 手机处于同一个虚拟私有局域网；
   * 你的手机在 Tailscale 里会获得一个固定内网 IP（例如 `100.88.99.10`）；
   * 朋友在异地直接输入：`http://100.88.99.10:8088/live.m3u` 就能直接顺畅收看，画质毫无损失！

## 第四部分：朋友常问的疑难排查 (FAQ)

### Q1：手机发热厉害吗？会影响电池寿命吗？
* **解答**：完全不会。Termux 运行的是轻量文本转发与流转接服务，CPU 占用率通常不足 2%，整机温度和待机时一样清凉；建议开启手机电池保护模式（充到 80% 停止），更加安全耐用。

### Q2：电视提示“连接超时”或“无法加载订阅”？
* **解答**：排查以下两点：
  1. 确认电视和这台 Termux 手机连接的是**同一个路由器发出的 Wi-Fi**（不要一个连主路由，一个连访客网络，访客网络会相互隔离）；
  2. 手机 IP 偶尔会变动：建议在路由器管理后台，将这台 Termux 手机的 MAC 地址绑定为**固定静态 IP**。

### Q3：换台为什么比普通电视软件还快？
* **解答**：因为你的局域网手机作为“就近网关”缓存并清洗了网络请求，没有开机广告、没有第三方中转服务器的流量劫持，直接由 TiviLite 播放器的硬件解码引擎直连加载，因此能做到毫秒级秒开秒播！
